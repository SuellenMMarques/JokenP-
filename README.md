# 🪨📄✂️ Jogo JokenPô

Projeto desenvolvido como resolução do desafio proposto por [Rodolfo Mori](https://www.instagram.com/rodolfomorii/) no [DevClub](https://www.devclub.com.br/), aprimorado com novas funcionalidades e design personalizado.

---

## 🎮 Sobre o Projeto

JokenPô é a versão digital do clássico jogo **Pedra, Papel e Tesoura**! O jogador desafia a **Alexa** (computador) escolhendo um dos três gestos. O resultado é calculado automaticamente e a pontuação é atualizada em tempo real.

---

## ✨ Funcionalidades

- Escolha entre Pedra ✊, Papel 🖐️ ou Tesoura ✌️
- Adversária virtual (Alexa) com escolha aleatória
- Placar em tempo real para o jogador e para a Alexa
- Botão para resetar a pontuação
- Menu de navegação responsivo com hamburguer menu no mobile
- Seções de Regras do Jogo e Como Jogar
- Design responsivo: mobile-first

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)

---

## 📱 Layout

O projeto foi desenvolvido com abordagem **mobile-first**, adaptando-se para telas maiores através de media queries nos breakpoints de `768px` e `1024px`.

---

## 🧠 O que foi praticado

- Manipulação do DOM com `querySelector`, `querySelectorAll` e `getElementById`
- Eventos de clique com `addEventListener`
- Lógica condicional com `if/else`
- Geração de número aleatório com `Math.random()` e `Math.floor()`
- Manipulação de classes com `classList.toggle`, `classList.add` e `classList.remove`
- Escopo de variáveis em JavaScript
- Menu hamburguer funcional com detecção de clique fora do elemento
- CSS Grid e Flexbox
- Variáveis CSS com `custom properties`
- Posicionamento com `position: relative` e `absolute`
